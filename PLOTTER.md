# LaserGRBL — режим плоттера (нож / drag knife)

Форк `LaserGRBL-knife` под станок с **пассивным поворотным лезвием**, без оси Z.

## Профиль станка (зафиксировано владельцем)

| Параметр | Значение |
|---|---|
| Лезвие | Пассивный swivel, offset от оси поворота |
| Подъём | Нет — высота выставляется вручную (часто 0 мм от стола, сквозной рез) |
| Прошивка | GRBL 1.1 |
| Поле | ~400×400 мм |
| Материалы | Резина, бумага, картон до ~2 мм |
| Траектория | **Непрерывный рез**: переезды между контурами тоже режут (G1) |
| Порядок | Сначала **внешние** контуры |
| Компенсация | Только blade offset (drag-knife arcs) |

### Термины

- **Kiss-cut** — надрез верхнего слоя (типично винил), подложка цела. У вас пока не нужен: высота ручная, рез насквозь.
- **Lead-in** — короткий подход до контура, чтобы лезвие развернулось до начала фигуры (мм, 0 = выкл).
- **Overcut** — небольшой дорез за замыкание контура, чтобы угол гарантированно прорезался (мм, 0 = выкл).

## Возможности

- Меню **Grbl → Плоттер / настройки ножа...** (русский UI)
- Непрерывный рез, AlwaysDown, drag-knife compensation
- Импорт: растр→вектор, SVG, **DXF** (LINE / LWPOLYLINE / POLYLINE / CIRCLE / ARC), готовый G-code
- В режиме плоттера скрыты лазерные тесты / Material DB / статистика лазера
- Сборка: portable ZIP + Inno Setup (`setup-knife.iss`) через GitHub Actions

## Быстрый старт

1. Установите/распакуйте релиз
2. **Grbl → Плоттер / настройки ножа...** → включите режим
3. Задайте **смещение лезвия** (мм от оси до острия) — измерьте штангенциркулем
4. Скорость реза под материал (старт ~600–1200 мм/мин)
5. Откройте SVG / DXF / картинку (Vectorize) → проверьте траекторию на превью → пробный проход
