# LaserGRBL — режим плоттера (нож / drag knife)

Форк `LaserGRBL-knife`: управление GRBL-станком с **пассивным поворотным лезвием** вместо лазера.

## Что уже сделано (каркас)

- Меню **Grbl → Plotter / Knife settings...**
- Параметры: смещение лезвия, угол поворота, скорости, способ подъёма/опускания (M3/M5, ось Z, свои команды), lead-in / overcut, оптимизация порядка контуров
- Включение **drag-knife compensation** из унаследованного кода GRBL-Plotter при генерации SVG→G-code
- Для векторизации растра: nearest-neighbour + inner-first при включённом режиме плоттера
- CI: `.github/workflows/windows-release.yml` — сборка portable ZIP на Windows runner

## План работ

1. **Каркас настроек и drag-knife** ← текущий этап  
2. Уточнение механики по ответам (см. вопросы ниже)  
3. Доработка SVG: сбор контуров → сортировка → lead-in / overcut в геометрии  
4. Адаптация UI импорта (подписи «нож» вместо «лазер», скрытие мощности при Z-режиме)  
5. Превью пути с дугами компенсации  
6. Релиз portable ZIP (+ опционально Inno Setup) через GitHub Actions / tag `v*`

## Сборка на Windows

См. [BUILD_WINDOWS.md](BUILD_WINDOWS.md). На Linux-агенте полноценный WinExe не собирается — релиз идёт через Actions.

## Вопросы для уточнения

Ответьте по пунктам — от этого зависят следующие правки.

### A. Механика ножа

1. **Смещение лезвия (blade offset)** — расстояние от оси поворота держателя до острия (мм)? Есть ли штангенциркуль / паспорт держателя?
2. Лезвие **только пассивное** (swivel / drag knife), без активного сервопривода угла?
3. Как **опускается / поднимается** нож?
   - a) соленоид / серво на пине spindle (M3/M5 или PWM S)  
   - b) ось Z (какие Z-down / Z-up?)  
   - c) другое (опишите команды)
4. Нужна ли **пауза M0** перед первым уколом / перед каждым контуром?

### B. Станок и прошивка

5. Контроллер: **GRBL 1.1** / Ortur / Smoothie / Marlin / другое?
6. Есть ли ось **Z** в прошивке и механике?
7. Рабочее поле (мм) и типичная **скорость реза** / **скорость холостого хода**?
8. Материал: винил, бумага, картон, ткань, другое? Толщина?

### C. Файлы и траектории

9. Основные исходники: **SVG**, растр (JPG/PNG) через векторизацию, DXF (сейчас нет), готовый G-code?
10. Нужен ли **надрез (kiss-cut)** vs **сквозной рез** разными параметрами?
11. **Lead-in / overcut** — используете? Какие длины (мм)?
12. Для замкнутых контуров: резать **сначала внутренние** отверстия (рекомендуется)?
13. Нужна ли **компенсация толщины линии** (offset path наружу/внутрь), или только drag-knife offset?

### D. UI и продукт

14. Режим плоттера: **глобальный переключатель** (как сейчас) или отдельное приложение / профиль?
15. Язык UI: достаточно английских подписей или нужен **русский**?
16. Оставить лазерные функции рядом или спрятать в режиме плоттера?

### E. Релиз

17. Предпочтительный формат: **portable ZIP** (exe + dll) или **установщик** (Inno Setup)?
18. Целевая ОС: Windows 10/11 x64? (сборка переведена на **.NET Framework 4.8**)
19. Собирать релизы с **GitHub Releases** этого репозитория `MNSerg/LaserGRBL-knife`?

### F. Тесты

20. Есть ли тестовый SVG / фото ножа / пример «хорошего» G-code с другого ПО (GRBL-Plotter, VinylMaster и т.п.)?
